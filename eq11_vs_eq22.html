재검토: 22번의 "차" 형태와 $C_\Omega$ 부호 — 네 지적이 맞다

이전 버전에서 "11번 = 22번은 항상 동치"라고 단언했는데, 두 지적(① 차 형태가 KL 전용 아니냐 / ② $V(s')$ 쪽 $\alpha$ 부호)을 정의·코드 기준으로 다시 따져보니 정정이 필요해.

요약 평결.
① 차 형태: "Bregman divergence ⇒ KL 전용"이라는 네 직관은 수학적으로 맞아 (f-divergence ∩ Bregman = KL뿐, Amari). 다만 코드는 차를 Bregman으로 계산하지 않고 f-divergence gradient 단일 항으로 계산해서 비껴가. 그래서 표기는 헷갈리지만 코드 자체는 모든 divergence에서 일관됨. 표기상 문제는 인정, 코드 동작은 OK.
② 부호: 네 지적이 맞다. 11번을 telescoping 하면 $C_\Omega$ 는 $-\gamma\alpha$ (음수)로 나와야 하고, 레포 자신의 Eq 14도 음수로 적혀 있어. 그런데 Eq 22와 코드는 $+\alpha$ (양수, $\gamma$ 없음). 내부 불일치가 실재해.

등장하는 식 4개 (레포 기준)

Eq 11 · original (이미지 2) $$ r(s,a) = \alpha\big[\nabla_\pi\Omega(\pi^*(\cdot|s);\pi_{\mathrm{ref}})\big]_a + \beta(s) - \gamma\,\mathbb{E}_{s'}\big[V^*(s')\big] $$ Eq 13 · 정의 (inner_term.py:5) $$ C_\Omega(\pi;\pi_{\mathrm{ref}}) = \mathbb{E}_{a\sim\pi}\big[[\nabla\Omega(\pi)]_a\big] - \Omega(\pi) = \mathbb{E}_{a\sim\pi}[\Phi(u_a)],\quad \Phi(u)=f'(u)-\tfrac{f(u)}{u} $$ Eq 14 · 레포가 직접 적은 전개 (inner_term.py:4) $$ r(s,a) = \alpha[\nabla\Omega(\pi^*)]_a + \beta(s) \;\color{#c0392b}{-\;\gamma\alpha}\,\mathbb{E}_{s'}\big[C_\Omega(\pi^*(\cdot|s'))\big] - \gamma\,\mathbb{E}_{s'}[\beta(s')] $$ Eq 22 · trajectory-DPO (이미지 1) $$ \hat r_\theta(s,a) = \alpha\big[\nabla\Omega(\pi_\theta(\cdot|s))(a) - \nabla\Omega(\pi_{\mathrm{ref}}(\cdot|s))(a)\big] \;\color{#9b59d0}{+\;\alpha}\,C_\Omega(\pi_\theta(\cdot|s')) $$

Eq 14는 Eq 11의 $V^*(s')$ 자리에 $V^*=\alpha C_\Omega+\beta$ 를 대입한 것 — 레포 본인이 음수 $-\gamma\alpha$ 로 적어놨다는 게 ②의 핵심 증거야.

① 차 형태 $\nabla\Omega(\pi_\theta)-\nabla\Omega(\pi_{\mathrm{ref}})$ — 네 직관과 코드의 실제

▶ 부분 인정. "차 = Bregman = KL 전용"은 옳은 명제다. 단, 코드는 그 함정을 f-divergence gradient로 우회한다.

네 말이 맞는 부분 — Bregman으로 읽으면 KL뿐

차를 공유 생성함수 $\phi$ 의 mirror-map gradient $\phi'(\pi_\theta)-\phi'(\pi_{\mathrm{ref}})$ 로 읽으면, 그건 Bregman divergence $B_\phi(\pi_\theta\|\pi_{\mathrm{ref}})$ 의 gradient야. 그리고 f-divergence가 동시에 Bregman divergence인 경우는 KL뿐 (Amari). 예를 들어 $\chi^2$:

$$ \nabla_\pi D_{\chi^2}(\pi\|\mathrm{ref})_a = f'(\pi_a/\mathrm{ref}_a)=2\big(\tfrac{\pi_a}{\mathrm{ref}_a}-1\big) $$

이건 $\pi_a/\mathrm{ref}_a$ 라는 비(ratio)에 의존해서, $\phi'(\pi_a)-\phi'(\mathrm{ref}_a)$ 처럼 "$\pi_a$ 만의 함수 − $\mathrm{ref}_a$ 만의 함수"로 분리되지 않아. 즉 $\chi^2$ 를 만드는 생성함수 $\phi$ 는 존재하지 않고, 차 표기를 Bregman으로 해석하면 $\chi^2$·Hellinger·JS·α-div에서는 의미가 없어. 여기까진 네 지적이 정확.

코드가 비껴가는 방식 — 단일 f-div gradient

그런데 코드는 차를 계산하지 않아. $\Omega$ 를 f-divergence 범함수 $D_f(\cdot\|\pi_{\mathrm{ref}})$ 로 보고 gradient 한 항 $f'(\pi_\theta/\mathrm{ref})$ 만 써:

# regularizers.py:222-228 — 단일 항, 뺄셈 없음 def grad(self, p, ref=None): ... return self.spec.fp(p / ref) # f'(π/ref) grad_dpo = grad # math.js:70 (χ²) gradDPO: p => p.map(x => 2*(3*x - 1)) // f'(π/ref), ref=1/3

이 "단일 항" 해석에서는 $\nabla\Omega(\pi_{\mathrm{ref}})_a = f'(\mathrm{ref}_a/\mathrm{ref}_a)=f'(1)$ = 행동마다 같은 상수. 게다가 이 코드는 $\pi_{\mathrm{ref}}$ 가 균등(1/3)이라 어떤 해석으로 봐도 뺄셈 항은 상수이고, 고정 depth 궤적의 BT 차 $d=S_w-S_l$ 에서 상쇄돼. 그래서 코드는 차를 빼든 안 빼든 결과가 같고, 모든 divergence에서 Eq 11(f-div gradient)과 일치해.

해석$\nabla\Omega(\pi_\theta)-\nabla\Omega(\pi_{\mathrm{ref}})$비-KL에서
(A) f-divergence 범함수$f'(\pi_\theta/\mathrm{ref}) - \underbrace{f'(1)}_{\text{상수}}$단일 항과 동일(상수차) — 코드와 일치
(B) Bregman 생성함수$\phi'(\pi_\theta) - \phi'(\pi_{\mathrm{ref}})$$\phi$ 가 존재 안 함 — KL 전용

내 의견: Eq 22의 "차" 표기는 (B)로 읽히기 쉬워서 네가 의심한 게 정당해. 하지만 논문/코드가 실제로 쓰는 건 (A)라서, 결과적으론 옳고 KL 전용도 아냐. 표기가 느슨한 것이고, "Eq 11이 Bregman 차로 귀결된다"는 내 이전 서술은 과장이었어 — 정정. 정확히는 "둘 다 단일 항 $f'(\pi/\mathrm{ref})$ 로 환원된다"가 맞아.

② $C_\Omega$ (=$V(s')$ 전개) 부호 — 네 지적이 맞다

▶ 인정. 11번 telescoping은 $-\gamma\alpha\,C_\Omega$ 를 주고, 레포 Eq 14도 음수. 그런데 Eq 22·코드는 $+\alpha\,C_\Omega$. 부호가 뒤집혔고 $\gamma$ 도 빠졌다.

유도 (11번 → 궤적 점수)

정류 조건에서 $Q^*(s,a)=\alpha[\nabla\Omega(\pi^*)]_a+\beta(s)$, 그리고

$$ V^*(s)=\mathbb{E}_{\pi^*}[Q^*]-\alpha\Omega(\pi^*)=\alpha\,C_\Omega(\pi^*(\cdot|s))+\beta(s) \;\Rightarrow\; \beta(s)=V^*(s)-\alpha\,C_\Omega(\pi^*(\cdot|s)) $$

궤적 할인수익 $G=\sum_t\gamma^t r(s_t,a_t)$ 에 Eq 11을 넣고 $V^*$ 를 telescoping 하면:

$$ G = \alpha\sum_t\gamma^t[\nabla\Omega(\pi^*(\cdot|s_t))]_{a_t}\;\color{#c0392b}{-\;\alpha\sum_t\gamma^t\,C_\Omega(\pi^*(\cdot|s_t))}\;+\;\underbrace{V^*(s_0)-\gamma^T V^*(s_T)}_{\text{BT에서 상쇄}} $$

BT 차에서 시작상태 $s_0$ 항도 상쇄되므로, 살아남는 per-transition 점수는

$$ \hat r(s,a)\;\propto\;\alpha[\nabla\Omega(\pi(\cdot|s))]_a\;\color{#c0392b}{-\;\alpha\gamma\,C_\Omega(\pi(\cdot|s'))} $$

→ 음수, $\gamma$ 포함. 이건 레포의 Eq 14와 완전히 일치해.

그런데 코드는

# dpo.py:164-169 (score_traj) sc += alpha * R.grad_dpo(pols[l][s], ref[l, s])[a] # 할인 γ^t 없음 if sn >= 0: C, acts = draw_inner(pols[l + 1][sn], a_data, ref[l + 1, sn]) sc += alpha * C # +α C_Ω : 양수, γ 없음

JS도 동일 (`task3-admissibility.js:169-173`, `sc += aReg * di.C`). 즉 코드는 $+\alpha C_\Omega$, $\gamma$ 없음 — Eq 22와는 일치하지만 Eq 11/Eq 14와는 부호·$\gamma$ 가 어긋나.

그래도 admissibility 결론은 안 흔들리는 이유

  • 분산은 부호에 무관: 논문의 핵심 주장은 $C_\Omega$ 추정량의 분산이야. $\mathrm{Var}[+C_\Omega]=\mathrm{Var}[-C_\Omega]$ 이고 $\gamma$ 배는 상수배일 뿐 → "KL은 noise-free, 나머지는 $\propto 1/\sqrt{n}$" 라는 fingerprint는 그대로.
  • KL은 부호와 무관하게 상쇄: $\Phi_{\mathrm{KL}}\equiv1$ 이라 $C_\Omega^{\mathrm{KL}}$ 는 상수 → 고정 depth BT 차에서 부호/γ가 어떻든 사라짐. KL의 π* 복원은 정확.
▶ 단, 정량적 주의. 비-KL의 경우 부호가 틀리면 $\pi_\theta$ 가 $\pi^*$ 에서 체계적으로 편향될 수 있어. policy 패널의 비-KL 편차 중 일부는 "inner-term noise"가 아니라 이 부호/γ 불일치 때문일 가능성이 있고, 둘이 섞여 보일 수 있다는 점은 비판거리야. 결론(정성적 fingerprint)은 살지만, 정량 복원은 의심해볼 만해.

종합 의견

  1. ① — 네 "Bregman ⇒ KL 전용" 직관은 정확. Eq 22의 차 표기는 그 오해를 부르지만, 코드는 단일 f-div gradient라 모든 divergence에서 동작은 맞음. 내 이전 "동치" 단언은 과장 → 정정: "둘 다 $f'(\pi/\mathrm{ref})$ 단일 항으로 환원".
  2. ② — 부호는 네가 맞아. Eq 11·Eq 14는 $-\gamma\alpha C_\Omega$, Eq 22·코드는 $+\alpha C_\Omega$. 명백한 내부 불일치(부호 뒤집힘 + $\gamma$ 누락). 분산 기반 admissibility 결론은 무사하지만, 비-KL 정량 복원에는 편향을 줄 수 있음.
  3. 권고 — 코드 `dpo.py:168` 의 sc += alpha * C 를 sc -= alpha * cfg.gamma * C (또는 Eq 14에 맞춘 부호/γ)로 바꿔 비-KL 복원이 개선되는지 확인해볼 가치가 있어. KL 결과는 어차피 안 바뀜.

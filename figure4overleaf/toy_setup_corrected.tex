\subsection{Setup}
\label{app:toy-setup}

\paragraph{Environment.}
Fig.~\ref{fig:toy-mdp} shows the toy environment. It is a \emph{layered} MDP with
$H=4$ decision layers, $S=3$ states per layer and $|\mathcal{A}|=3$ actions, so a policy is a
$4\times3\times3$ table of action distributions and there are $|\mathcal{S}|=12$ state--layer
cells. Transitions depend only on the action and are stochastic: from any state of layer
$\ell$, action $a$ reaches state $a$ of layer $\ell+1$ with probability $1-\epsilon$ and each
of the two remaining states with probability $\epsilon/2$, with $\epsilon=0.2$. Rewards
$r(\ell,s,a)\sim\mathrm{Unif}(-0.8,0.8)$ are drawn i.i.d.\ on \emph{every} (layer, state,
action) triple once per seed and held fixed for that seed; the discount is $\gamma=0.9$. Each
trajectory starts from a uniformly drawn layer-$0$ state and runs for exactly $H$ steps. The
reference policy $\pi_{\mathrm{ref}}$ is uniform on every state. We instantiate seven
regularizers from Tab.~1, namely reverse KL (RKL), $\alpha$-divergence at $\alpha=0.5$,
forward KL (FKL), Jensen--Shannon, squared Hellinger, Pearson $\chi^2$, and squared Euclidean.
Preferences are generated by a Bradley--Terry oracle on \emph{discounted} trajectory returns at
temperature $\beta_{\mathrm{or}}=1$. Training fits tabular logits with the trajectory-DPO loss
($6000$ preference pairs, $400$ steps, batch $16$, learning rate $0.08$); the regularization
weight $\alpha$ is \emph{not} fixed but calibrated per (regularizer, target peak) by bisection,
so that all seven $\Omega$ are compared at matched policy sharpness. Every cell is averaged over
$100$ independently drawn MDPs (one training seed each).

All seven regularizers, including KL, use the same per-step Monte-Carlo budget. In the
\emph{on-policy} regime, $n_{\mathrm{mc}}$ samples are drawn at every non-terminal next-state to
estimate the inner term $\bar\Psi$; in the \emph{off-policy} regime the single logged next action
$a'$ is used instead, so $n_{\mathrm{mc}}$ does not apply. This keeps the per-step compute matched
across $\Omega$ and prevents any sampling-budget advantage from confounding the variance
comparison. For KL, the $n_{\mathrm{mc}}$ draws have no effect ($\bar\Psi_{\mathrm{KL}}\equiv1$
collapses every sample to the same constant, so $n_{\mathrm{mc}}$ cannot change the KL gradient),
but the samples are still drawn.

\subsection{Toy layered MDP}
\label{app:toy-mdp}

The multi-step environment is a layered (trellis) MDP, not a tree. There are $H=4$ decision
layers, each with $S=3$ states, and $|\mathcal{A}|=3$ actions, giving $|\mathcal{S}|=12$
state--layer cells. Transitions are stochastic and depend only on the action: from any state of
layer $\ell$, action $a$ moves to state $a$ of layer $\ell+1$ with probability $1-\epsilon=0.8$,
and to each of the other two states with probability $\epsilon/2=0.1$ (so $\epsilon=0.2$). The
last layer is terminal: its actions collect reward but bootstrap no successor. Per-triple rewards
$r(\ell,s,a)\sim\mathrm{Unif}(-0.8,0.8)$ are sampled once per random seed and held fixed for that
seed, and the discount is $\gamma=0.9$. Trajectories start from a uniformly drawn layer-$0$ state
and run for exactly $H$ steps. The reference policy is uniform,
$\pi_{\mathrm{ref}}(a\mid s)=1/|\mathcal{A}|$ at every state.

# Bregman Lab Suite

Interactive labs for the **general convex regularizer policy-deviation theorem** and the
**off-policy admissibility of KL divergence** in regularized MDPs / direct preference optimization.

A written **Experiments** section (Part 0) plus three interactive tasks, switchable from the left sidebar:

0. **Experiments** — a conference-style write-up of the off-policy admissibility study (calibration, inner-term statistics, the n_mc and depth sweeps, and the extreme off-policy regime), with result tables generated by the Admissibility lab.
1. **Dual Manifold (3D)** — the primal regularizer surface Ω(π) over the policy simplex and the
   conjugate surface Ω*(q) over the gauge-quotiented Q-space, with tangent planes, the
   Bregman/Fenchel–Young gap, and the order-reversed duality identity B_Ω(π‖π*) = B_Ω*(q*‖q).
2. **Theorem Live** — a layered stochastic MDP where π* is *computed* from user-set rewards and
   temperature; click edges to set rewards and read Q*, Q^π, and the value gap (LHS), then sample
   Monte-Carlo rollouts whose mean converges to the discounted Bregman sum (RHS).
3. **Off-Policy Admissibility** — train tabular trajectory-DPO under seven regularizers on the
   *same* MDP and *same* preference data, with per-divergence α calibrated to a common policy peak.
   The inner term C_Ω(s') is Monte-Carlo estimated for non-KL regularizers (KL needs none, since
   C_Ω is constant). Training curves, final policy-gap bars (± seed std), a C_Ω statistics panel,
   and π* vs π_θ comparison panels reveal KL's admissibility signature.

## Seven divergences

KL · α-divergence (a = 1.5) · Reverse KL · Jensen–Shannon · squared Hellinger · Pearson χ² ·
squared Euclidean. Each ships an exact simplex argmax solver (softmax / bisection on the
stationarity inverse / simplex projection), a Bregman closed form, the inner integrand Φ, and its
derivative Φ′ (used by the A-direction gradient).

## Running

No build step. Any static server works:

```bash
npm run dev          # uses `npx serve` on http://localhost:5173
# or
python3 -m http.server 5173
# or: VS Code "Live Server" extension (Open with Live Server)
```

Then open the served `index.html`. (Opening the file directly via `file://` will fail because ES
modules require an HTTP origin.)

Three.js r128 loads from a CDN; everything else is dependency-free vanilla JS + SVG.

## Task 3 controls

- **target peak** (0.4–0.9) — mean over states of max_a π*(a|s); α per divergence is bisection-calibrated to hit it. An α–peak sweep panel plots peak(α) for all seven divergences with the target line and each calibrated α marked.
- **n_mc** — Monte-Carlo samples for the inner term C_Ω(s'), drawn *per transition* (not per trajectory).
- **N_pairs / seeds** — preference-dataset size and number of training seeds (bars show ± seed std).
- **ε** — transition noise: action a reaches its target next state w.p. 1−ε, else uniform over the rest.
- **batch (2ⁿ)** — SGD minibatch size; smaller batches let the inner-term estimator variance survive
  averaging, making the admissibility gap more visible.
- **A / B mode** — gradient handling of the inner term:
  - **A** (default, faithful): propagates ∂Ĉ_Ω/∂θ through the *same* a' samples used for the value,
    using each divergence's Φ′. This is the theoretically correct trajectory-DPO gradient.
  - **B** (approximate): lets the inner-term noise enter only through the BT logit d and hence the
    scalar gradient scale (stop-grad on ∂Ĉ/∂θ). Kept for comparison.

## Downloads

Task 3 exports: the α–peak sweep, training curves, policy-gap bars, and π* vs π_θ panels each as **SVG**, plus the full run (alphas, per-seed final gaps, mean/std, and all settings) as **JSON**. Filenames encode the settings stamp (peak, ε, batch, gradient mode, off-policy).

## Notes on faithfulness

The A-direction gradient is exact up to the Monte-Carlo estimation of C_Ω itself; KL is the unique
case where C_Ω is constant in π, so its estimator is noise-free at every n_mc — that is the
admissibility property the experiment is built to expose.
